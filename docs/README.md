# Calculator API Documentation

A robust REST API for performing arithmetic calculations with comprehensive error handling and batch processing capabilities.

## Features

- **Single Calculations**: Perform individual arithmetic operations
- **Batch Processing**: Execute multiple calculations in a single request
- **Error Handling**: Comprehensive validation and error reporting
- **Precision Management**: Handles floating-point precision up to 10 decimal places
- **Overflow Protection**: Prevents arithmetic overflow errors
- **CORS Support**: Cross-origin resource sharing enabled
